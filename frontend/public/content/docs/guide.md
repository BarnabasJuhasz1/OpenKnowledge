# Using OpenKnowledge

OpenKnowledge is a free, open-source platform for literature reviews —
discovering papers across major academic databases, scoring their relevance,
and mapping how the research connects.

## Getting started

1. Open [My Projects](/dashboard/projects) from the Dashboard and create a project.
2. Inside your project, pick a feature from the left panel and describe what you are looking for in the search bar.
3. Refine results with the OK-score weights, then save what matters to your Library.

## Features

**Research** — Run a boolean search over the Semantic Scholar corpus. Results
are ranked by OK-score and paginated as you browse. (This alpha searches
Semantic Scholar; more sources are planned.)

**OK-score** — A composite relevancy score combining citation counts, code
availability, peer-review status, data openness and repository stars. Tune the
weights to match what matters for your review.

**Graph** — Visualize the top results as an interactive citation network laid
out by year. Expand a node to pull in the papers it cites or that cite it, and
inspect any paper in the detail panel.

**Library** — Save queries to your shelf and bookmark individual papers to your
bookshelf so you can return to a line of inquiry without re-running the search.

**Cit-Graph** — Build a citation graph from a single seed paper by DOI,
Semantic Scholar ID or arXiv ID, with community detection to surface clusters
of related work.
